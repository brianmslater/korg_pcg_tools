# PCG Tools Python

Cross-platform Korg PCG file editor - a Python rewrite of the original PCG Tools.

## Purpose
Edit and manage patch data for Korg synthesizers (Kronos, Oasys, Triton, M3, Krome, etc.)

## Key Features
- Open/save PCG files from all supported Korg synthesizers
- Edit program and combi patches (names, categories, favorites)
- Full setlist editing (16 setlists × 128 slots each)
- Copy/paste patches within and between files
- GM2 banks support (read-only ROM banks)
- CLI for automation and batch processing
- Hardware-tested on Korg Kronos 2

## Interfaces
- Qt GUI (PySide6) - primary interface
- CLI (click) - automation and scripting

## Target Users
Musicians and sound designers working with Korg workstation synthesizers who need to organize, edit, and manage their PCG patch files.
