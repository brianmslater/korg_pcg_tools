  EASIEST WAY TO START
================================================================================

1. Double-click:  launch_gui.bat
   
   This will open the graphical interface where you can:
   - Open PCG files
   - Browse programs and combis
   - Export patch lists

2. In the GUI:
   - Click "File → Open PCG..." to load your PCG file
   - Browse programs and combis in the tabs
   - Use "Tools → Export Patch List..." to save data

================================================================================
  COMMAND LINE USAGE
================================================================================

Open PowerShell or Command Prompt in this folder, then:

# Get information about a PCG file
python -m pcg_tools info yourfile.pcg

# List all patches
python -m pcg_tools list-patches yourfile.pcg

# Export to CSV
python -m pcg_tools export yourfile.pcg output.csv

# Launch GUI
python -m pcg_tools gui

# Get help
python -m pcg_tools --help

================================================================================
  EXAMPLE: WORKING WITH YOUR PCG FILES
================================================================================

1. Copy your PCG file to this folder, OR use full path:

   python -m pcg_tools info "C:\Users\YourName\Documents\myfile.pcg"

2. Export patch list to your desktop:

   python -m pcg_tools export myfile.pcg "C:\Users\YourName\Desktop\patches.csv"

3. Open in Excel or any spreadsheet program to view!
